# OTHERSELF — episode 01: The last light

A small vulnerable observer borrows the authority and weight of station workers to reach the last coastal shuttle. Direction + action + possess/return. No combat, inventory, countdown, server or analytics.

Four rooms: observation vestibule; wet sorting; glass garden; roadstead dock. Gatekeeper hand readers unlock a short path; technician gear controls open a covered alternative. Only Nim crosses room boundaries and low passages. Two optional sail creatures, three endings, backtracking before final bell. Possession checks distance/facing/line of sight for 0.6 seconds; abandoned body remains vulnerable. Guards investigate audible transitions and sealed machinery, detect continuously for 2 seconds; release recovery takes 2 seconds. Checkpoints at safe entries and rescued creatures.

Art: oxidized teal station, wet slate walkways, amber pools of light, huge layered architecture, small moss-green Nim with amber eyes, no ears or eyebrows. Rust scarf and graphite mantle. Fully rendered 3D scene, side camera; no background image masquerading as gameplay. Responsive editorial shell: restrained ivory lettering, orange status accents, dark glass HUD, spatial labels.

Resource budget: <=150k visible triangles, DPR capped at 1.5 (1 for low), one shadow-casting key light, shared geometry/materials, 1024px texture ceiling. Target 60 desktop/30 mobile fps subject to measured validation. Fixed logic step 1/60, bounded frame delta; pause on hidden tab. All assets local. Separate deterministic world state, rendering, audio and interface. Explicit mount/start/pause/resume/destroy integration.

Implementation contract: src/engine.js exports createGame(), step(state,dt,input), action(state), possess(state), getTarget(state), getInteraction(state), serialize(state), restore(json), retry(state), ROOMS. Input {move:-1|0|1}. State {phase:'playing'|'lost'|'won',room:0..3,nim:{x,facing},controlled:null|guardId,rooms:[{guards:[{id,role:'keeper'|'tech',x,facing,alert,recovery}],gateOpen,bridgeOpen,rescued,mechanism}],time,events:[],checkpoint}. Each room x 0..36, ground y0; movement and all sight tests in same plane. ROOMS items {key,length,gateX,readerX,consoleX,crateX,covers:[{from,to}],glass:[{x}],guards:[...]}. Renderer reads only. getTarget returns guard or null; getInteraction returns {key,x} or null. events use {type,...}; callers drain after processing. Rendering may decorate safely but must reflect engine obstacles/doors/covers. Engine author may extend contract, notify collaborators.
